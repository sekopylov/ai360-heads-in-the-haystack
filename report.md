# Отчёт

Дата: 2026-10-09. Подробности — в [PLAN.md](PLAN.md), ячейки запуска — в [RUNS.md](RUNS.md).

## Сделано

**1. Код перенесён на новые библиотеки.** Перехват внимания и маскирование голов работают через стандартный механизм `transformers`, без правленых копий модельных файлов авторов. Код не привязан к одной модели: проверен на Qwen1.5-14B-Chat и Qwen3-8B.

**2. Новый код сверен со старым.** Qwen1.5-14B-Chat, 40 примеров, одинаковые входы.

| | Новый против старого | Новый сам с собой при смене ядра внимания |
|---|---|---|
| Скоры голов: корреляция; лучшие 50 | 0,994; 50 из 50 | 0,990; 49 из 50 |
| Успех примера совпал | 40 из 40 | 40 из 40 |
| Ответы идентичны | 26 из 40 | 29 из 40 |

Расхождение со старым кодом не больше, чем у нового кода с самим собой при другом порядке вычислений. Это погрешность половинной точности. Устойчивы агрегаты (скоры голов, доля успешных примеров), отдельные ответы между реализациями не воспроизводятся.

**3. Добавлен конвейер.** Генераторы задач → прогон → файлы → метрики. Прогон и метрики — отдельные процессы, общаются только через файлы со скользящим окном; прерванный прогон продолжается с места остановки. На Qwen3-8B конвейер дал те же результаты, что сверенный код: ответы совпали в 18 из 18 примеров, метрики голов — до шестого знака.

Попутно получен эталон на коде авторов: детекция на Qwen1.5-14B-Chat воспроизвела авторскую (20 лучших голов совпали полностью).

## Дальше

3. **Построение конвейеров:** генераторы задач и метрики под них.
