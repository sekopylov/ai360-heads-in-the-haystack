# Маска лучших голов по массе внимания: прогоны ветки `c0`

Ответы модели из прогона `qwen3-8b-no-thinking-paul-graham-new-mass-top5-40` (ветка `c0`, завершён 2026-10-10). Сохранены, чтобы сравнивать с нашим перебором масок без повторного запуска.

- **Модель:** Qwen3-8B без thinking, fp16.
- **Рейтинг голов:** `needle_attention_mass_v1` из прогона без thinking — тот же файл, что у нас `data/head_scores/head_scores_needle_attention_mass_v1_2.json`.
- **Маска:** логиты головы обнуляются (равномерное внимание), только на шагах генерации — как у нас.
- **Задача:** игла про Сан-Франциско в эссе Пола Грэма, 20 длин × 10 глубин, лимит ответа 256 токенов. Сетка совпадает с нашим перебором `results/new/qwen3_mask`.
- **Отличие от наших прогонов:** стог начинается со случайного места корпуса (`context_seed` 42), у нас — с начала.

## `cases.jsonl`

1800 строк: 9 условий (0, 5, 10, 15, 20, 25, 30, 35, 40 отключённых голов) × 200 примеров. Поля названы как в наших `samples.jsonl`:

| Поле | Значение |
|---|---|
| `heads` | число отключённых голов; 0 — без маски |
| `context_length`, `depth_percent` | точка сетки |
| `reference`, `response` | эталон и ответ модели |
| `n_tokens` | длина ответа в токенах |
| `stopped` | ответ закончился сам, а не по лимиту |
| `rouge1_recall`, `success` | ROUGE-1 recall из исходного файла и признак «выше 50» |

Исходный архив содержал также токены ответа, время и ROUGE-2/3; здесь оставлено то, что нужно для пересчёта метрик ответа.
